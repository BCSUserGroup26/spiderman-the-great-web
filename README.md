# Spider-Man: The Great Web — Recovery Project

## About the project

I am the creator of this recovery project, which is based on a version of Spider-Man: The Great Web that I found. My goal is to recover what I can and work on porting it into a playable state.

Alongside being a recovery project, this is also a test of my skills in making a PS5 game. This is my first time doing this, and I am the only person working on it. I am learning as I go, so some parts may be rough or poorly implemented, and the overall quality may fall short of expectations.

## Current status

**The game has not finished porting yet. This project is incomplete.**

Depending on when you visit this project, the repository may be empty or contain only early work, and there may be no releases available to download. The existence of this project does not mean a playable build is already available.

The original game was scrapped before the map was finalised, so this recovery should not be expected to feel like a finished game. It may contain bugs, missing content, unfinished areas, and crashes.

## Known issues

- **Unfinished map:** The game was scrapped before the map was finalised. Areas may be incomplete or missing.
- **Broken cutscenes:** Most of the original cutscenes broke. I recorded replacement cutscenes and included them as MP4 videos instead.
- **Suit changes during cutscenes:** Recorded cutscenes do not reflect the player's currently selected suit. A character's suit may change when a cutscene starts and change back when gameplay resumes.
- **Suit issues:** Some suits may be bugged, and some suits are not currently available.
- **Audio does not currently work:** I have not found the original audio for any cutscene or character. I have tried my best to find suitable replacement SFX, but audio remains incomplete and is not currently working.
- **Multiplayer crashes:** Multiplayer is currently broken and crashes when used. It is not currently playable.
- **Incomplete port:** Features and content may be missing or fail to work while porting is still underway. A bug-free experience is not guaranteed.

## PS5 requirements

To run a PS5 build when one becomes available, you need:

- A jailbroken PS5.
- Kstuff Lite.
- ShadowMount+.

Build-specific installation instructions and any additional requirements will be provided with a release.

## Before playing

Please treat any available build as an unfinished recovery in progress. Expect bugs, incomplete content, bugged or unavailable suits, cutscene suit mismatches, missing audio, and possible crashes. Multiplayer currently crashes and should be avoided.

Check the project's release page for an actual downloadable build. If there are no releases, there is currently no published build available from this project.
